# Custom functions and callbacks

#### Custom callbacks

| Identifier | Name             | Arguments | Return value | Description                                                   |
|:----------:|:-----------------|:---------:|:------------:|:--------------------------------------------------------------|


Identifiers below 0x2000 are reserved for standardized functions and callbacks.

Numbers above that range are considered private and can be used without assignment in the registry.

Random number in the private range should be used for private extensions and functions and callbacks under active development.

Once the custom function or callback is finalized and implemented in a subset of hosts and SDKs, it will be assigned identifier
in the standardized range.
